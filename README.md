Welcome to my personal portfolio website! This project showcases my skills, experiences, and the projects I've built as a developer. 

## 🚀 Tech Stack
*   **Frontend:** React.js, HTML5, CSS3, JavaScript (ES6+)
*   **Build Tool:** Vite (or Create React App, depending on your setup)
*   **Deployment:** GitHub Pages / Vercel / Netlify *(Choose yours)*

## 🛠️ Features
*   **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
*   **Project Showcase:** A curated list of my best work with live links and source code.

*   **Contact Form:** A way for recruiters and clients to get in touch with me.
